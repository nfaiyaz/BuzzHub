# BuzzHub

A full-stack social media application built with Next.js, Express.js, PostgreSQL, and Prisma.

## Tech Stack

### Frontend
- Next.js
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- JWT
- bcryptjs

### Database
- PostgreSQL
- Prisma ORM

## Features

- User registration and login
- User profiles
- Create posts
- View posts
- Comments
- Like/unlike posts
- Follow/unfollow users
